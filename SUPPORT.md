# Support

Use GitHub Issues and Discussions for public support.

## Good public support requests

- CLI, API, or Web UI bugs with synthetic reproduction text.
- New deterministic check proposals.
- Ruleset coverage gaps.
- Documentation fixes.
- Packaging, CI, or GitHub Action integration questions.

## Do not post publicly

- Unpublished manuscripts.
- Confidential peer-review or editorial material.
- Participant data or personal information.
- Security vulnerabilities.
- Private API keys, tokens, logs, or credentials.

For security concerns, follow `SECURITY.md`.

## Triage expectations

OpenRI is early-stage OSS. Maintainers prioritize:

1. Bugs that can silently drop evidence or mark unsupported material as safe.
2. Security, privacy, and unpublished-manuscript handling.
3. Deterministic checks with clear fixtures.
4. API/CLI compatibility and packaging.
5. UI and documentation improvements.
