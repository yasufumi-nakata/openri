OpenRI Tutorial / Packages

OpenRI package registry

GitHub Pages から取得できる OpenRI の配布物です。未公開原稿を外部 API へ送らない既定値は、CLI、API、MCP、Codex skill の各入口で維持します。

Python

wheel と source distribution、checksum、SPDX metadata を公開します。

pip install https://www.yasufumi.net/openri/packages/python/openri-0.3.2-py3-none-any.whl

npm client

OpenRI API を呼ぶ軽量 ESM client です。

npm install https://www.yasufumi.net/openri/packages/npm/openri-client-0.3.2.tgz

MCP server

ローカル OpenRI API を MCP tool として公開します。

npm install https://www.yasufumi.net/openri/packages/mcp/openri-mcp-0.3.2.tgz

Codex skill

原稿検査、report 解釈、AI reviewer protocol 確認用の skill です。

curl -LO https://www.yasufumi.net/openri/packages/skill/openri-codex-skill-0.3.2.tar.gz
