GitHub Pages tutorial

OpenRI を投稿前・査読前チェックとして動かす。

OpenRI は研究不正や採否を自動断定する仕組みではありません。原稿の統計、透明性、引用、PDF不可視テキスト、隠し指示、AI reviewer protocol を、証拠付きの確認タスクとして返します。

チュートリアルを始める 結果の読み方

ローカル実行、API 実行、GitHub Actions への組み込みまでを同じ流れで確認できます。

最短の始め方

まずはサンプル原稿を CLI で走らせ、次に Web UI と API で同じ report を確認します。

1. Install

開発版では PDF、network、server、dev extras をまとめて入れます。

pip install -e ".[pdf,network,server,dev]"

2. Run CLI

高リスクサンプルで統計・透明性・引用・隠し指示を確認します。

openri check samples/high_risk_manuscript.txt

3. Review

score ではなく、finding の evidence と reviewer task を見ます。

openri show <report_id> --json

何を確認するか

OpenRI は合格印を出すより、査読前に止めるべき論点と未確認領域を明示することを優先します。

統計と透明性

p 値再計算、GRIM 風の平均値/n 確認、ethics・data・code・COI・funding 記載を確認します。

引用とPDF

DOI、本文中引用、参考文献、PDF の不可視文字・注釈・埋め込みファイルを確認します。

AI reviewer protocol

AI reviewer assignment、claim inventory、coverage blocker、adversarial challenge を report に含めます。
